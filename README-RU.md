# PSL Scanner v0.6 — Progress & Comparison

## Новое

- сравнение любых двух сохранённых анализов;
- базовый анализ;
- 3D-карта изменений поверхности с диапазоном −4…+4 мм;
- выравнивание meshes по стабильной центральной верхней зоне;
- маска ненадёжных вершин;
- графики PSL, симметрии, качества и повторяемости;
- заметки и ручной вес для каждого анализа;
- диагностика качества измерения;
- PDF-отчёт;
- зашифрованная резервная копия истории с паролем;
- восстановление резервной копии после переустановки;
- хранение до 50 последних анализов.

## Важно

Карта изменений показывает разницу наружной поверхности. Она не показывает изменения костей и не является медицинским исследованием. Разница 1–2 мм может быть вызвана мимикой, положением головы и шумом TrueDepth.

## Загрузка

Распакуй архив обновления и загрузи его содержимое в корень GitHub-репозитория с заменой файлов. Workflow соберёт unsigned IPA автоматически.
