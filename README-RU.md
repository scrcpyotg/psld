# PSL Scanner v0.2 — TrueDepth 3D

Нативное iOS-приложение для локального сканирования наружной поверхности лица через ARKit и фронтальную TrueDepth-камеру.

## Что добавлено

- отдельный экран результатов после завершения скана;
- интерактивная вращаемая 3D-сетка;
- экспериментальный PSL-балл, диапазон и категория;
- показатель надёжности и предупреждения;
- 8 поверхностных 3D-прокси: симметрия, гармония, angularity, zygomatic, mandibular, chin, midface и nasal;
- оценка стабильности сетки между кадрами;
- подробные размеры и технические параметры скана;
- экспорт полного JSON;
- новая иконка приложения;
- версия приложения 0.2.0.

## Важно

TrueDepth измеряет наружную поверхность кожи. Приложение не видит внутренние кости, не заменяет КТ и не является медицинским инструментом. PSL-балл — экспериментальная демонстрационная калибровка, а не объективная мера привлекательности.

## Обновление репозитория через GitHub

1. Распакуйте архив полностью.
2. В репозитории откройте **Add file → Upload files**.
3. Загрузите содержимое архива с сохранением папок.
4. Убедитесь, что в корне есть `project.yml`, `PSLScanner`, `scripts` и `.github`.
5. Нажмите **Commit changes**.
6. Во вкладке **Actions** дождитесь новой сборки **Build unsigned IPA**.
7. Скачайте артефакт `PSLScanner-unsigned` и подпишите IPA привычным способом.

## Использование

1. Нажмите **Начать 3D-скан**.
2. Сначала смотрите прямо.
3. Медленно поверните голову в одну сторону, затем в другую.
4. Вернитесь в центр, сохраняя нейтральную мимику.
5. После обработки откроется экран результатов.
6. 3D-сетку можно вращать пальцем, а полный отчёт — сохранить в JSON.
