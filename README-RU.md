# PSL Scanner — нативный iOS TrueDepth alpha

Это первый нативный этап вместо сайта. Приложение:

- запускает `ARFaceTrackingConfiguration`;
- проверяет наличие настоящего `capturedDepthData`;
- собирает 90–150 стабильных кадров;
- отбрасывает сильный наклон, моргание, открытый рот и заметную улыбку;
- берёт медиану каждой вершины ARKit-сетки;
- считает базовые 3D-метрики и качество скана;
- сохраняет полную усреднённую сетку и треугольники в JSON.

В alpha **нет PSL-категории**. Сначала нужно проверить, насколько повторяются три скана одного человека. Иначе новая формула снова будет выглядеть точной, но давать нестабильные категории.

## Сборка IPA через GitHub с Windows

1. Создайте пустой репозиторий GitHub.
2. Загрузите в него всё содержимое этой папки, включая `.github`.
3. Откройте вкладку **Actions**.
4. Выберите **Build unsigned IPA**.
5. Нажмите **Run workflow**.
6. После завершения откройте выполненный workflow.
7. В разделе **Artifacts** скачайте `PSLScanner-unsigned`.
8. Внутри будет `PSLScanner-unsigned.ipa`.

IPA собран без подписи. Перед установкой его нужно подписать вашим обычным способом. Bundle ID по умолчанию:

`com.psllens.scanner`

## Использование

1. Запустите приложение и разрешите камеру.
2. Держите iPhone вертикально на расстоянии 30–50 см.
3. Нажмите **Начать 3D-скан**.
4. Сначала смотрите прямо.
5. Медленно поверните голову в одну сторону, затем в другую.
6. Вернитесь в центр.
7. После обработки нажмите **JSON** и сохраните файл.

Для проверки повторяемости сделайте три скана подряд при одинаковом свете и без изменения выражения лица.

## Ограничения

TrueDepth и ARKit измеряют наружную поверхность лица, а не внутренние кости. Сканы нельзя трактовать как КТ, медицинскую диагностику или прямое измерение sphenoid, lacrimal, maxilla либо mandible.
