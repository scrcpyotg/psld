# PSL Scanner v0.3 — TrueDepth Depth Fusion

Нативное iOS-приложение для локального сканирования наружной поверхности лица.

## Что изменилось в v0.3

- ARKit face mesh объединяется с несколькими синхронными `capturedDepthData`-картами.
- Для каждой вершины приложение проецирует ARKit-точку в карту глубины и получает устойчивую медиану по нескольким кадрам.
- Ошибочные depth-пиксели отбрасываются по расстоянию до базовой ARKit-сетки.
- Временной шум, остаток глубины и покрытие контролируются отдельно.
- Коррекция каждой вершины ограничена, затем сглаживается только по соседям той же сетки.
- Если Depth Fusion не проходит контроль качества, приложение безопасно возвращается к медианной ARKit-сетке и расширяет диапазон результата.
- На экране результата можно переключаться между `Depth Fusion` и `ARKit base`.
- JSON содержит обе сетки и подробные метрики объединения.

## Что означает Depth Fusion

Это уточнение наружной поверхности TrueDepth. Оно не получает сохранённый шаблон Face ID, не видит внутренние кости и не заменяет медицинскую визуализацию.

В `depthFusion` JSON сохраняются:

- применено ли объединение;
- число depth-кадров;
- число уточнённых вершин;
- процент покрытия;
- медианный остаток в миллиметрах;
- временной шум в миллиметрах;
- средний вес коррекции;
- качество и тип точности входных `AVDepthData`.

## Сборка IPA через GitHub Actions

1. Загрузите содержимое проекта в репозиторий GitHub.
2. Workflow `.github/workflows/build-ipa.yml` запустится автоматически.
3. После зелёной сборки скачайте artifact `PSLScanner-unsigned`.
4. Подпишите IPA своим обычным способом.

## Рекомендуемый скан

- расстояние 30–50 см;
- равномерный свет;
- нейтральное выражение;
- медленный поворот в обе стороны;
- не закрывать лицо волосами или рукой.
