# PSL Scanner v0.4 — Scan Reliability

Нативный iPhone-сканер наружной поверхности лица через ARKit и фронтальную TrueDepth-камеру.

## Главное в v0.4

- серия из трёх последовательных сканов;
- пять автоматически контролируемых позиций головы в каждом скане;
- сравнение одинаковых вершин между сканами;
- медианная и P90-погрешность в миллиметрах;
- процент стабильных вершин;
- цветная 3D-карта повторяемости;
- финальная категория только после трёх согласованных сканов;
- экспорт JSON, OBJ и PLY;
- PLY содержит цветовую карту погрешности;
- сохранены ARKit base mesh и Depth Fusion mesh.

## Как обновить GitHub

1. Распакуйте архив обновления.
2. Откройте репозиторий GitHub.
3. Нажмите `Code → Add file → Upload files`.
4. Перетащите всё содержимое распакованной папки.
5. Подтвердите замену существующих файлов.
6. Нажмите `Commit changes`.
7. GitHub Actions автоматически соберёт новый unsigned IPA.

## Как сканировать

Каждый скан состоит из пяти этапов:

1. прямо;
2. первый боковой ракурс;
3. снова прямо;
4. противоположный боковой ракурс;
5. финальный анфас.

После первого и второго скана показывается предварительный результат. После третьего приложение рассчитывает повторяемость. Если сетки расходятся сильнее допуска, категория скрывается и показывается `НЕТ ЗАМЕРА`.

## Экспорт

- JSON — все метрики, обе сетки и массив погрешности по вершинам;
- OBJ — итоговая 3D-сетка;
- PLY — итоговая сетка с цветами карты погрешности.

## Ограничения

TrueDepth и ARKit измеряют наружную поверхность кожи. Это не КТ, не медицинское исследование и не прямое измерение внутренних костей. PSL-балл остаётся экспериментальной визуальной калибровкой.
