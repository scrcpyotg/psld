# PSL Scanner v0.5 — 3D Feature Metrics + локальный кабинет

Нативное iOS-приложение для локального анализа наружной поверхности лица через ARKit и TrueDepth.

## Что добавлено в v0.5

- расширенные 3D surface-метрики;
- confidence каждой метрики;
- разброс значений между тремя сканами;
- региональная симметрия: лоб, орбитальная зона, скулы, нос, рот, челюсть и подбородок;
- цветная карта асимметрии;
- цветная карта локальной кривизны;
- режимы mesh: Depth Fusion, ARKit base, погрешность, асимметрия и кривизна;
- вкладки результатов: итог, 3D-метрики, симметрия и mesh;
- локальный личный кабинет;
- автоматическое сохранение последних 20 завершённых анализов;
- просмотр сохранённого mesh и метрик;
- сравнение результата с предыдущим анализом;
- удаление одного анализа, всей истории или профиля;
- необязательная защита кабинета через Face ID/код-пароль устройства.

## Хранение данных

Профиль и история не отправляются на сервер. Полные JSON-документы хранятся в Application Support приложения на iPhone. При удалении приложения iOS удаляет локальную историю.

Сохраняются только завершённые серии из трёх сканов. Повторный показ одного результата не создаёт дубликат.

## Важные ограничения

TrueDepth и ARKit измеряют наружную поверхность лица. Названия zygomatic, mandibular, orbital и midface являются surface proxy и не означают прямое измерение костей. Результат не является медицинским заключением и не является объективной мерой привлекательности.

## Обновление через GitHub

1. Распакуйте `psl-scanner-ios-v0.5-update.zip`.
2. Откройте репозиторий GitHub.
3. Нажмите **Code → Add file → Upload files**.
4. Перетащите всё содержимое распакованной папки.
5. Разрешите замену существующих файлов.
6. Нажмите **Commit changes**.
7. Дождитесь зелёной сборки в **Actions**.
8. Скачайте artifact `PSLScanner-unsigned`.

Workflow `build-ipa.yml` менять не нужно.
