PSL Scanner v0.6

1. Распакуй psl-scanner-ios-v0.6-update.zip.
2. GitHub → Code → Add file → Upload files.
3. Перетащи всё содержимое распакованной папки.
4. Разреши замену существующих файлов.
5. Commit changes.
6. Actions → дождись зелёной сборки.
7. Скачай PSLScanner-unsigned.ipa из Artifacts.

build-ipa.yml менять не нужно.
