PSL Scanner v0.5

1. Распакуйте архив обновления.
2. В GitHub откройте Code -> Add file -> Upload files.
3. Загрузите всё содержимое папки с сохранением структуры.
4. Подтвердите замену существующих файлов.
5. Нажмите Commit changes.
6. Новая сборка IPA запустится автоматически.

Новые папки/файлы:
- PSLScanner/Account/LocalAccountStore.swift
- PSLScanner/Account/ScanHistoryStore.swift
- PSLScanner/Account/BiometricLock.swift
- PSLScanner/Scanner/SurfaceMetricAnalyzer.swift
- PSLScanner/UI/HistoryView.swift
- PSLScanner/UI/AccountView.swift

Важно: не загружайте сам ZIP как один файл.
