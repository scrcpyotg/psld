PSL Scanner v0.4

1. Распакуйте psl-scanner-ios-v0.4-update.zip.
2. GitHub → Code → Add file → Upload files.
3. Перетащите всё содержимое распакованной папки.
4. Нажмите Commit changes.
5. Дождитесь зелёной сборки во вкладке Actions.
6. Скачайте новый artifact PSLScanner-unsigned.

Старый build-ipa.yml менять не требуется.
